# SquadVsMonster — Steam 스토어 설명 (한국어)

## 짧은 설명 (최대 29단어)

스쿼드를 편성하고, 보스를 읽고, 패배 후 조합을 바꿔라. 매 전투가 다음 판단의 근거가 되는 세션형 보스 공략 자동전투 게임.

---

## 전체 설명

**SquadVsMonster**는 스쿼드 편성이 시작일 뿐인 세션형 보스 공략 자동전투 게임입니다. 전투 전에는 조합 프리뷰로 이번 빌드가 화력형인지, 방어가 얇은지, 사거리가 섞였는지 확인합니다. 전투는 자동으로 진행되지만 HUD는 계속 정보를 전달합니다 — 보스 약점 부위, 방벽 압박, 재장전 상태, 스쿼드 역할 분담이 실시간으로 업데이트됩니다.

전투가 끝나면 결과 화면이 이번 패배가 어디서 났는지 한 줄로 알려줍니다 — 생존 붕괴, 화력 부족, 재장전 겹침, 마무리 타이밍 실패 중 하나. 그 정보를 들고 스쿼드를 조정하고 다시 도전합니다.

**핵심 루프:**
- 스쿼드 역할을 설정하고 조합 프리뷰를 확인한다
- 자동전투 중 보스 약점과 재장전 타이밍을 읽는다
- 결과 요약과 cue line으로 패배 원인을 파악한다
- 스쿼드를 조정하고 재도전한다

**주요 특징:**
- 전투 전 조합 프리뷰 — 화력/방어/포지션 성향을 전투 시작 전에 확인
- 실시간 CombatAdvisor HUD — 보스 부위, 방벽 위협, 재장전 수, 다운 수
- 한 줄 cue가 포함된 결과 요약 — 생존/화력/재장전/타이밍 중 어디서 졌는지 즉시 파악
- 보스 부위별 약점 우선순위 (CORE / CHEST / LEG / ARM)
- 빠른 세션 — 대부분의 한 판이 30초 이내, 짧은 휴식 시간에도 완주 가능

**이런 분께 추천합니다:**
자동전투 RPG나 모바일 보스 공략 게임을 좋아하면서 "내 조합이 왜 이겼고 왜 졌는지"를 숫자 폭발 너머로 이해하고 싶은 분께 SquadVsMonster가 그 명확함의 순간을 드립니다.
